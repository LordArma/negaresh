# نگارش

نگارش افزونه‌ای برای وردپرس است که نگارش فارسی نوشته‌ها را درست می‌کند: نیم‌فاصله‌ها، ارقام فارسی،
نشانه‌گذاری، گیومه و موارد دیگر. [English](README.md)

![تنظیمات ← نگارش: کادر «امتحان کنید» متن را همان‌طور که می‌نویسید اصلاح می‌کند](screenshot.png "نگارش")

## دریافت
فایل `negaresh.zip` را از آخرین نسخه در [صفحهٔ نسخه‌ها](https://github.com/LordArma/negaresh/releases) دریافت
کنید و در «افزونه‌ها ← افزودن ← بارگذاری افزونه» بارگذاری کنید.

## پیش‌نیازها
* وردپرس ۵٫۸ یا تازه‌تر (آزموده تا ۷٫۱)
* PHP نسخهٔ ۷٫۴ یا تازه‌تر

## امکانات
بر پایهٔ کتابخانهٔ [ویراستار](https://github.com/AlirezaSedghi/Virastar) (نسخه‌ای اصلاح‌شده همراه افزونه است).

* **اصلاح هنگام ذخیره یا هنگام نمایش.** متن ذخیره‌شده هنگام ذخیرهٔ نوشته اصلاح شود (پیش‌فرض نصب‌های تازه)،
  یا فقط متنی که نمایش داده می‌شود اصلاح شود و متن ذخیره‌شده هرگز تغییر نکند.
* **۳۲ قاعده** که در «تنظیمات ← نگارش» روشن یا خاموش می‌شوند، هر کدام با یک نمونه، و کادر **امتحان کنید**
  که متن خودتان را با گزینه‌های انتخاب‌شده اصلاح می‌کند.
* **فقط متن تغییر می‌کند:** برچسب‌های HTML، ویژگی‌ها، پیوندها، کدهای کوتاه و کد (`pre`، `code`،
  `script`، `style` و …) دست‌نخورده می‌مانند؛ متن تمام‌انگلیسی هم همین‌طور.
* **این نوشته را تغییر نده** از نوار کناری ویرایشگر (یا کادر ویرایشگر کلاسیک)، یا بخشی از نوشته با
  کلاس CSS به نام `negaresh-skip` یا `data-negaresh="off"`.
* **همین حالا این نوشته را اصلاح کن** در ویرایشگر بلوک؛ با «واگرد» برمی‌گردد.
* **اصلاح نوشته‌های موجود** در «ابزارها ← نگارش» یا با WP-CLI، پس از دیدن خط‌های تغییرکرده. متن پیش از
  هر تغییر در نسخه‌های ذخیره‌شدهٔ همان نوشته نگه داشته می‌شود.
* اصلاح عنوان‌ها و خلاصه‌های دستی (اختیاری)، و انتخاب نوع نوشته‌ها، خوراک‌ها و REST API.
* ترجمهٔ کامل فارسی.

## WP-CLI

<div dir="ltr">

```bash
wp negaresh fix                      # what would change (nothing is saved)
wp negaresh fix --apply --diff       # fix every post in scope and print the changed lines
wp negaresh text "کتاب ها ?"          # fix a piece of text
```
